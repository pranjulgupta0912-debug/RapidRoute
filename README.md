# RapidRoute — Intelligent Emergency Response System

A simple but visually polished Advanced Data Structures & Algorithms project.

## DSA used
- Graph / weighted graph
- Adjacency-list style edge data
- Dijkstra shortest path
- Priority-based emergency queue (UI prototype)
- Hash-map style records (can be added next)

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Presentation story
Emergency requests arrive with different priorities. RapidRoute helps dispatch an ambulance and calculate the shortest route to a hospital. The core DSA is a weighted graph plus Dijkstra's shortest-path algorithm.
